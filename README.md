# 知语 · 高中语文分层研习

首版教学应用，沿用原型界面，现已连接真实后端与数据库。支持单教师登录、文章导入与编辑、知识点拆解与编辑、基础/巩固/拓展题库、学生专属作答链接、教师诊断评分、关联原作答的巩固训练。

## 本地运行

要求 Python 3.10+，无 Node 构建步骤。

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
# 使用安全终端设置环境变量，值不要提交到 Git。
export ZHIYU_ADMIN_USER=teacher
read -r -s -p '设置教师初始密码（至少12位）: ' ZHIYU_ADMIN_PASSWORD
export ZHIYU_ADMIN_PASSWORD
.venv/bin/uvicorn backend.main:app --host 127.0.0.1 --port 8001 --no-access-log
```

默认 SQLite 保存到 `data/zhiyu.db`，不再使用浏览器 localStorage。正式部署使用项目专属 MySQL；`DATABASE_URL` 示例见 `.env.example`。密码仅在首次初始化账号时生效，后续不会自动重置密码。数据库只创建 `zhiyu_` 前缀表，不删除已有数据。后续结构升级需要数据库迁移，当前为首版初始化。

## 教学闭环

1. 保存文章 → 创建知识点，或从文体建议选择方向后完善可观察的知识点。
2. 每个知识点配置基础、巩固、拓展题目，填写训练材料、问题、参考答案与评分标准。
3. 为学生生成任务链接，私发给该学生。链接持有者可以查看并提交一次作答。
4. 教师查看作答，填写得分、具体问题标签、依据与反馈。学生复核前看不到参考答案和评分标准。
5. 从同一知识点选另一道题创建关联再练。学生在原任务页刷新即可看到反馈和巩固入口。

已分发的题目锁定，不允许修改题干或评分依据；修改需求应新建题目。文章、知识点和未分发题目可编辑。刷新页面数据仍然保留。

## AI 接入

当前按用户要求完成教师主导流程，不连接外部 AI。`backend/ai.py` 定义文章拆解、出题和诊断的结构化接口，后续适配服务商，并由教师确认后入库。不以关键词匹配冒充自动评分。

## 文章、知识点、题目三维联动

导航将文章和知识点查题合并为“题库”，递进选择文章及本篇知识点后跨文章找题。原有186条题组/草稿及新增84道客观题保留各自来源、原ID与实际阅读材料，教师训练题、任务和批改不因此改写。

- 文章题目：选择文章，查看正文、材料解析、已确认知识点、各知识点题数及这篇的题目。无题文章明确显示暂无题目；选篇列表选择后自动收起，可重新展开。
- 知识点题目：选择通用知识点，查看涉及文章及仅属于该知识点的题目。文章和题目分别每页10条，不把同篇的其他题目混入。
- 题目详情：显示可点击的文章标签、知识点标签、阅读材料、题干、答案、解析、评分信息和来源；可返回文章、知识点、原题库或所属分层训练。原题库、分层训练和知识点库也有直达入口。

标签索引依据现有外键、题库标签、题干及带原文依据的解析动态计算，不覆盖教师数据；未经教师确认的标签不会自动生成已确认知识点。使用通用标签过滤泛用断句方法中的修辞名词，现有186条题库记录均有文章、知识点两个维度。导入题目无知识点标签时显示“知识点待确认”，不捏造标签。阅读材料按正文规范化去重，内置574条材料对应556个正文节点，保留全部186条题目；同一正文的不同来源和标题别名合并索引，原题来源仍可单独查看。

左侧“题库”合并原“文章题目”和“知识点题目”。知识点选择放在首位，不选文章也能直接选择全部可见知识点，列出跨文章的相关题目。参考文章为可选项，输入部分篇名、作者或两者组合可即时模糊匹配，点击结果或用方向键及回车选中，选中后结果列表自动收起。搜索复用当前账号已加载的文章索引，不逐字发送请求；可清除文章并保留当前知识点。选定参考文章后可查看本篇知识点，选择其中一项或“本篇全部知识点”查题；切换参考文章时保留仍适用的知识点，不适用的选择自动清空。支持层次、关键词、分页和清空筛选；点击题目知识点标签直接进入该知识点的跨文章题目列表。题目详情仍在可关闭子页面中查看，可选用至个人分层训练草稿；原题与已有任务不改写，私人题目及筛选选项按账号隔离。

题目详情在可关闭的独立子页面中打开，支持顶部“关闭题目”按钮及Esc键；关闭后保留原筛选、分页与浏览位置。详情页中的“选用此题”继续进入个人训练草稿编辑。

### 请求与索引缓存

文章库在当前登录会话的浏览器内存中复用，切换栏目不重复下载全文；退出登录时清空。个人工作区每次切换仍刷新，以及时获取学生作答。API 保留 `Cache-Control: no-store`，支持 gzip 压缩；不把私人数据放入浏览器持久缓存或共享 HTTP 缓存。

后端对材料、知识点分组和题目关联索引使用按账号隔离的进程内缓存，30 秒过期，最多保留 12 个派生对象。教学记录或材料提交修改时清除缓存；登录鉴权与学生任务响应不缓存。多进程部署时其他进程最多延迟 30 秒更新；重启服务自动清空，无需 Redis 或数据库改动。
