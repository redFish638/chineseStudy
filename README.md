# 知语 · 高中语文分层研习

首版教学应用，沿用原型界面，现已连接真实后端与数据库。支持单教师登录、文章导入与编辑、知识点拆解与编辑、基础/巩固/拓展题库、学生专属作答链接、教师诊断评分、关联原作答的巩固训练。

## 本地运行

要求 Python 3.10+，无 Node 构建步骤。

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
# 使用安全终端设置环境变量，值不要提交到 Git。
export ZHIYU_ADMIN_USER=teacher
read -r -s -p '设置教师初始密码（至少12位）: ' ZHIYU_ADMIN_PASSWORD
export ZHIYU_ADMIN_PASSWORD
.venv/bin/uvicorn backend.main:app --host 127.0.0.1 --port 8001 --no-access-log
```

默认 SQLite 保存到 `data/zhiyu.db`，不再使用浏览器 localStorage。正式部署使用项目专属 MySQL；`DATABASE_URL` 示例见 `.env.example`。密码仅在首次初始化账号时生效，后续不会自动重置密码。数据库只创建 `zhiyu_` 前缀表，不删除已有数据。后续结构升级需要数据库迁移，当前为首版初始化。

## 教学闭环

1. 保存文章 → 创建知识点，或从文体建议选择方向后完善可观察的学习目标。
2. 每个知识点配置基础、巩固、拓展题目，填写训练材料、问题、参考答案与评分标准。
3. 为学生生成任务链接，私发给该学生。链接持有者可以查看并提交一次作答。
4. 教师查看作答，填写得分、具体问题标签、依据与反馈。学生复核前看不到参考答案和评分标准。
5. 从同一知识点选另一道题创建关联再练。学生在原任务页刷新即可看到反馈和巩固入口。

已分发的题目锁定，不允许修改题干或评分依据；修改需求应新建题目。文章、知识点和未分发题目可编辑。刷新页面数据仍然保留。

## AI 接入

当前按用户要求完成教师主导流程，不连接外部 AI。`backend/ai.py` 定义文章拆解、出题和诊断的结构化接口，后续适配服务商，并由教师确认后入库。不以关键词匹配冒充自动评分。

## 检查

```sh
.venv/bin/python -m pytest -q
node --check app.js
```

`tests/test_workflow.py` 覆盖权限、答案保密、提交、评分、分层再练和持久化。浏览器集成检查见 `tests/browser.cjs`，需要 Playwright 与可用 Chromium，通过临时数据库运行，不接触生产数据。可用 `python tests/run_browser.py` 启动临时测试服务并执行浏览器验收；需要 Node 环境能够解析 playwright，及系统 Chromium 或 Playwright 浏览器。

## 部署与范围

Ubuntu + systemd + Nginx + MySQL 部署步骤见 [deploy/README.md](deploy/README.md)。模板不含真实凭据。服务器状态以部署脚本健康检查和服务器实际验收为准。

这是单教师、小范围教学试用首版，学生以专属链接访问。尚无班级批量分发、学生账号、多教师隔离、任务撤销及数据导出。现有网页原型的浏览器记录不会自动迁入新数据库。

## 文章库与自动拆解（本次更新）

首页可直接搜索和选择课文/训练材料，不再要求先手动录入。目录现已扩充至192条，包含9篇原有课文与训练选篇及29组公开古诗阅读材料；具体原文状态和参考范围见下文“扩充选篇目录”。

选择材料后自动展示知识点、原文依据、学习目标、解析和三个层次的训练方向。可勾选并修改，确认后入库；不会自动覆盖已有知识点。确认时验证文章未变、引文在原文中，同名知识点跳过。分层题库可匹配自编练习草稿和公开真题候选，教师审核后保存。

默认解析来自内置教研笔记或公开题目解析提取，并明确标注非AI。可选实时AI适配支持 OpenAI 兼容接口，在安全的服务器配置中设置 `ZHIYU_AI_BASE_URL`（HTTPS，通常以 `/v1` 结尾）、`ZHIYU_AI_MODEL` 和 `ZHIYU_AI_API_KEY`。不要把密钥写进仓库或聊天。只有点击“使用AI重新分析”或对无内置解析文章请求分析时，才会向所配置服务发送正文。AI结果必须通过引文与结构检查并经教师确认。不发送学生作答；此版本未开启AI评分。

已部署服务器更新代码：在 Git 检出目录 `git pull --ff-only` 后执行 `sudo .venv/bin/python deploy/update_service.py`。此更新不改变依赖、账号或环境配置；新版本可增加独立题库表，保留原有教学表及记录，备份旧代码后更新 `/opt/zhiyu` 并重启后台；失败时尝试恢复。首次安装脚本不能代替升级脚本。

来源、收录范围和限制见 [SOURCES.md](SOURCES.md)。

## 知识点 → 其他相关文章与配套题

“文章题库 · 关联推荐”提供独立数据库题库：571条材料（111组公开真题、365篇补充诗作、9篇原有选篇、86条增补原文材料），包含186条原题组/练习草稿。知识点确认后，卡片自动预览其他相关文章；不用自己搜索、下载并粘贴正文。可查看匹配标签、原文定位和来源解析，按来源/文体/年份/知识点/有无题目筛选，查看全文并将原题、答案、解析带入原知识点的训练草稿。

推荐基于统一标签，非AI向量检索；同一正文去重、当前作品排除，跨字形/节选差异仍需教师核对。原题没有官方难度字段时标为“未分层”，选作训练暂选“巩固”并提示教师调整。文集主题标签关联较弱，且可能没有题目，不冒充配套题库。模拟题内置数量为0；已有模拟卷或获授权题库可在页面使用JSON模板批量导入，每次最多100篇、800KB，单篇正文最多15000字符。重复材料合并并补充新题，来源保留为教师提供、未外部核验。

本版本启动时仅新增 `zhiyu_bank_materials`、`zhiyu_bank_exercises` 独立表并初始化公开数据，不重建原数据库，不改教师密码和已有作答。公开快照通过版本更新补充，教师导入记录不会被初始化覆盖。当前是数百条规模的本地标签检索；不是全网实时爬虫，也不是已接入所有商业题库。

571条题库材料均有可展示的解析/研读辅助：101条匹配篇目笔记、107条保留公开来源解析、363条提供规则辅助研读提示。规则只定位可见的景物语汇、情感词、关联语、句式与首尾信息等，不自动断定全篇主旨、用典出处或标准答案；独立标注“内置研读解析（规则辅助）”。已知篇目或来源笔记在相同标签匹配程度下优先于规则提示。题库详情可直接展开解析与三级训练方向，选作教学文章后仍需教师勾选确认，之后才能进入已确认知识点及关联训练。

## 知识点库：确认知识点 → 索引文章

导航新增“知识点库”。文章解析勾选确认后（或教师手动保存后），已有 `Point` 记录自动进入知识点索引；历史已保存内容也会直接出现，无须重新确认或导入，不增加数据库表。

可按知识点名称、文章标题、解析内容搜索及按关联文章文体筛选。相同名称按Unicode规范化及空白规范化归组，不自动合并语义相近的不同名称。一个条目显示关联文章数和训练题数，详情逐篇保留原文依据、目标、解析、训练方向及各自知识点ID，能返回原文章、进入该文章的分层训练或查找其他推荐材料。推荐材料与已确认文章分开，不会因匹配标签自动进入知识点库。

知识点库是已确认记录的实时索引，原知识点编辑更名后索引随之更新；不覆盖原记录、题目、学生答案或批改。仅教师登录可访问，学生任务链接无权限浏览。列表支持分页，刷新或重新登录后仍可读取已保存内容。

接口：`GET /api/knowledge-library`、`GET /api/knowledge-library/{id}`。浏览器验收：`TEST_BROWSER_SCRIPT=tests/knowledge-browser.cjs python tests/run_browser.py`。
